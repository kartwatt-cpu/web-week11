近期学习计划

  1. 把 UI 写成 State 的函数

    先定 Props 形状，再写组件；界面不对先看 State，不再去 DOM 里找节点。

  2. 把更新写成新引用

    增删改一律先复制再改副本，连续更新用函数式更新，避免动作被覆盖。

  3. 把验证做成两条轨

    单测证明业务规则没被破坏，组件行为测试证明 UI 真的由 State 驱动。
